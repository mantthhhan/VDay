# Be My Valentine — Single Page

Simple Valentine-themed single-page site built with plain HTML, CSS, and JavaScript.

How to use
- Open `index.html` in a browser.
- (Optional) Add your background music file at `assets/music.mp3` and uncomment the `<source>` line in `index.html`.

Files
- `index.html` — main page
- `styles.css` — styling and animations
- `script.js` — interactive behavior (evasive No button, confetti)

Notes
- The No button will playfully move away when you approach it. The Yes button reveals a sweet message and hearts.
